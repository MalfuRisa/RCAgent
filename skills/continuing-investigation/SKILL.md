# 方法指导

先读当前TaskSpec、前序阶段答复、摘要中的已查内容、失败方法、假设与反证、缺口及source_id。复用同表字段和成功方法，需要时read_material精读；不重复摸索已知合同。摘要不是新证据。续作沿用原会话，但新task_id的结果另存，保留旧阶段与窗口；新窗口只能由Planner另派有理由的任务。压缩不改变当前任务范围，不影响其他Worker。历史案例明确标为历史，不能直接证明当前状态。不要求检查点ID或读取额度。

本指导不构成调查材料，不覆盖用户问题或原始工具合同。

按需参考：[示例](references/native-examples.md)。

本轮失败不把previous_stage旧正文复制为当前成果。沿用合法tools和scope，改变有效能力另派；收尾期不得再启动上下文摘要或调查。
