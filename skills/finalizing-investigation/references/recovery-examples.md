# 报告纠正

漏问题：查看当前问题清单，逐个明确处置；不要删除问题或用历史问题 ID 代替。
非法观测 ID：查看已登记成果；原文/候选 ID 不能当 observation_id。
没有正式观测但有相关已读材料：先在本地整理期登记；无法登记时保留真实失败与未决。

报告包已产生后，最终选择仍可能失败。按回执中的有效 packet/statement/未决集合修正，
不复制其他 run 的旧选择。来源或问题变化导致 stale 时，在共享预算内重新审阅，
不能重置整个任务、重复派远端任务或沿用过期包。

下一步建议是建议，不是已经执行的事实；不能在建议或局限里混入确定根因的断言。
没有真实修正额度时保持部分状态，保留原包与最后响应。
