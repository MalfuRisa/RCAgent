# 从失败计划中选择下一项增量

过去曾为目录没有的业务指标派任务，Worker 只能遍历元数据而没有新事实。
改进是把现有能力能回答的范围写清，无法获取的指标列入缺口，保留可执行任务。

另一个失败是同窗口重复查询却没有新增比较问题。先看是否已保存同目标/窗口/参数的结果；
本地精读可解决的缺口不重新远端 fetch。需要不同窗口/分页或强制刷新时则不能误用缓存。

历史成功调查可提供“怎样核实支持与反证”的经验，但旧节点、旧窗口、旧故障原因不能成为固定答案。
任务的 resource_id 和 question_ids 必须来自当前工作台；目录中的名称不自动代表已有数据。
