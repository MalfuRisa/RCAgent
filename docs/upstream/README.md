# Project provenance

RCAgent evolved from SRE-agent by Marcello Martini (https://github.com/martinimarcello00/SRE-agent). Original citation metadata is preserved here. This repository starts with an independent Baseline commit. Installation and the default product graph use this repository. The former Git remote and MCP-server submodule registration have been removed. Historical compatibility modules remain available for replay. This migration does not grant a new open-source license.
